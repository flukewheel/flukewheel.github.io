# Bookmark cursor and saved state

Submitted: 31 October 2026

The project owner confirmed that bookmarks saved correctly but the cursor showed a crossed-circle while clicking the toolbar bookmark icon.

## Changed

- Replaced the toolbar's disabled cursor with a neutral cursor when no discovery is available and a progress cursor while a save is running.
- Marked the reaction controls busy during a mutation and gave active reactions/bookmarks a visible selected style.

## Verified

- Desktop and mobile browser checks confirmed the bookmark cursor is a pointer when ready, progress while saving, and a pointer again when saved.
- Lint, typecheck, six unit tests and the production build passed.
