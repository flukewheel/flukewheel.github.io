# Wheel toolbar and reaction updates

Submitted: 5 November 2026

- The Dislike button now removes an existing dislike when clicked again, including its saved reason. Selecting a reason still applies or updates a dislike.
- The Bump button is now a square, icon-only Wheel button using the project wheel artwork. It turns slowly clockwise, pauses on hover, and smoothly accelerates and settles after a press. Reduced-motion settings stop the rotation.
- Copy link uses the original website URL and has the shorter label. A northeast-arrow action opens the original website in a new tab.
- Updated the related product text and browser tests. Lint, typecheck, unit tests, build, and focused desktop/mobile browser checks passed.
