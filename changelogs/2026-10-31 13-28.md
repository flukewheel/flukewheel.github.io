# Phase 4 hosted submission and moderation rollout

Submitted: 31 October 2026

Extended the Phase 4 checkpoint with report review, database-enforced report throttling, and bounded daily queues for manual catalogue rechecks. Ordinary catalogue edits no longer refresh a site's validation date.

Applied five additive Phase 4 migrations to the hosted development database, then deployed `admin-catalogue` with JWT verification and `submit-website` for guest intake. Hosted checks confirmed exact Pages-origin CORS, unsafe URL rejection, duplicate detection, administrator denial without authentication, and an idempotent pending suggestion. The temporary suggestion was removed after verification.

Published the frontend through GitHub Pages. A live browser check confirmed the suggestion form uses the hosted intake function and displays its duplicate response. Twenty-five stale catalogue entries were queued for manual recheck.

Locally, lint, typecheck, unit tests, production build, 34 desktop/mobile browser tests, the backend smoke script and the security advisor check passed. The remaining Phase 4 completion checks require a real administrator walkthrough and manual review of curated pages on the hosted origin. Details are in `docs/phase-4-progress.md`.
