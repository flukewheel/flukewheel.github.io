# Catalogue editing and address changes

- Enabled **Save website** whenever catalogue metadata changes, including categories and description. Private change notes are optional.
- Added an **Edit web address** control for existing catalogue entries. The admin function validates and normalizes the URL, rejects duplicates, and saves the address, metadata, and categories in one database transaction.
- Added a rollback-only database check for persisted edits and duplicate-address atomicity. Desktop and mobile browser checks verify saved values after switching between websites.
- Applied migration `20261108181508_catalogue_website_url_edit.sql` to the local and linked databases and deployed the updated `admin-catalogue` Edge Function.
