# Automatic link preview images

- On approval, Flukewheel now reads a site's Open Graph or Twitter image metadata, stores a valid JPEG, PNG or WebP image in the public thumbnail bucket, and associates it with the new catalogue entry. The shared card component then uses it in Recently Added, For You and other discovery listings.
- Added an administrator button in the catalogue to find a missing preview for an existing website. Editing an entry without a stored thumbnail also attempts discovery; changing the URL of an automatically sourced thumbnail clears the old association before looking up the new URL.
- Limited page and image reads by size and time. Destination URLs and each redirect must use public domains with public DNS addresses. Sites without metadata, unsupported image formats or inaccessible images retain the card fallback.
- Added parser and address checks, a local end-to-end image storage test, and corrected the Phase 8 approval integration fixture after the earlier removal of mandatory review notes. Local typecheck, lint, unit tests, build, security advisor and approval boundary checks passed.
