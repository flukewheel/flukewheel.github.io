# Permanent website deletion in Catalogue

Submitted: 31 October 2026

Added a Delete website control to the Catalogue editor. It requires the administrator to type the current website title before a permanent delete.

The server verifies administrator authority and executes the deletion in one database transaction. It removes the website, its category links and related submissions, plus bookmarks, Bump history and reactions from every account. Report and recheck records are removed through foreign-key cascades. Prior website and submission moderation events are removed; a minimal deletion audit retains counts without the website title or URL.

Local backend checks covered browser-role denial, an incorrect title, two accounts' bookmarks and reactions, three history entries, related submissions and absence of the deleted rows. Lint, typecheck and desktop/mobile admin browser tests passed.
