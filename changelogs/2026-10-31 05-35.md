# Remove profile pictures from Phase 3

Submitted: 31 October 2026

The project owner removed profile pictures from Flukewheel's requirements after the hosted upload failed. The owner confirmed hosted email confirmation, password recovery, Google sign-in with a pending viewer action, and interest persistence across logout and login.

## Changed

- Removed the profile picture upload control and the frontend request to `process-avatar`.
- Removed signed avatar URL fetching and avatar display. The account menu uses its standard person icon.
- Updated Phase 3 documentation and its browser test to match the revised product requirement. The backend avatar function and database fields remain deployed but are unused by the frontend.

## Verified

- Lint, typecheck, 12 unit tests, the production build, and all 30 desktop/mobile browser tests passed.
