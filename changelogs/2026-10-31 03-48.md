# Password reset in account settings

Submitted: 31 October 2026

The project owner noted that Profile and interests had no password-reset option. Added an Account security section with a button that emails a reset link to the signed-in account address. The link returns to the route where it was requested and uses the existing password-update flow.

Verified with lint, typecheck, six unit tests, a production build, and desktop/mobile browser checks that the button sends a reset request and shows confirmation.
