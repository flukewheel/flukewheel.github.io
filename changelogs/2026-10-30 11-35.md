# Phase 3 local accounts and profile implementation

Submitted: 30 October 2026 at 11:35 Europe/London

## Added

- Email registration, email/password login, Google sign-in entry points, password reset and password update screens.
- PKCE callback exchange on the static app entry URL, with internal-route restoration and useful failure feedback.
- Persistent session state, one auth subscription, private query-cache clearing on logout, and owner-scoped profile creation.
- Profile menu and settings for username, interests and avatar. Avatar upload uses the trusted `process-avatar` function and signed private image URLs.
- Guest Love, Dislike and Bookmark actions that resume once against their original website after login. Closing authentication cancels the pending action.
- A signed-in For You state using selected categories as a starting recommendation signal.
- Local avatar origin example and Phase 3 setup notes.

- All 22 desktop and mobile browser journeys passed, including signup, refresh, profile changes, avatar upload, logout, guest bookmark recovery, dislike reason persistence and password recovery through the app entry.
- The existing local avatar processor integration check passed.
